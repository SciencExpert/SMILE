🍷 Wine Dataset (UCI) : Etude de 3 cépages de vins Italien. 178 échantillons avec 13 mesures chimiques par échantillon: bien séparés, souvent utilisé comme benchmark de comparaison de K-means, Hierarchical, DBSCAN, ou GMM.

Run StatMate™ Clustering Module

StatMate™ Clustering manages and analyzes your dataset with multiple algorithms. Clusters can be visualized in 2D/3D, and detailed (❓) results are provided for each algorithm. No manual intervention needed. StatMate™ Clustering auto-initialises when the page loads.
Step 1️⃣: Load Dataset with 📂 Import Data: Import your chemical dataset (CSV/JSON) via existing StatMate™ data loader or input the data in the tab with ➕ Add Col. and ➕ Add Row.
Step 2️⃣: Clustering & Analysis : Once your data is ready, you can cluster it with ▶️RUN
✨Algorithm: Choose K-means, Hierarchical, DBSCAN, or GMM.
📊 Parameters: Set K (number of clusters), eps & minPts (DBSCAN), or iterations (GMM).
⚪ Clusterisation: Click Run to generate clusters.
👁️ Visualization: Display clusters in 2D or 3D; select X, Y, Z axes. Cluster centers shown in black.
📈 Detailed Results: Shows algorithm, parameters, cluster centers, GMM weights/covariances, Hierarchical linkage, DBSCAN sizes/noise, K-means inertia.

Use ♻️ Reset (footer) to restart, or return to the main StatMate™ menu.

📘 User Manual

Cluster View

StatMate™ Clustering

StatMate™ Clustering Provide an educational and analytical tool for clustering numerical datasets interactively in 2D or 3D. The programme includes four major unsupervised learning algorithms: K-means with fast partitioning and uses sum of squared distances; Hierarchical Clustering which produces linkage structure; DBSCAN which is a density-based clustering and finally a Gaussian Mixture Model (GMM) based on a probabilistic clustering.

Buttons & Commands

➕ Add Col. Add or ➖ Del. Col. Remove variables (column) from the table.
➕ Add Row Add or ➖ Del. Row Remove the last observation (row) from the table.
📂 Import Data: Load or 💾 Export Data Download the data CSV/txt/xls/json file.
🖶 Print Tab: Print the data table.File selected: Shows the name of the imported file.
