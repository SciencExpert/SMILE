📘 User Manual

Cluster Tree

StatMate™ Dendogram

StatMate™' Dendogram or Tree Clustering organises data into groups using a hierarchical tree structure. Users don't have to predefine the number of clusters. Instead, clusters form gradually by merging similar data points. The first axis of the dendrogram shows the samples, while the second axis shows the distance between the merged clusters. By analysing it, you can select the number of clusters that best fits your data.

Buttons & Commands

➕ Add Col. Add or ➖ Del. Col. Remove variables (column) from the table.
➕ Add Row Add or ➖ Del. Row Remove the last observation (row) from the table.
📂 Import Data: Load or 💾 Export Data Download the data CSV/txt/xls/json file.
🖶 Print Tab: Print the data table.File selected: Shows the name of the imported file.
