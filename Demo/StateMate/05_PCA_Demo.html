StatMate™ Principal Composant Analysis

StatMate™ Principal Component Analysis (PCA) is used to reduce dimensionality of large datasets. It transforms correlated variables into a smaller number of uncorrelated variables called principal components [Ck], which retain most of the variance in the original data.
