ChemioInfo User Manual

ChemioInfo performs molecular similarity searches, extracts molecular properties, applies dimensionality reduction (PCA/UMAP), and conducts clustering using PubChem data in order to highlight meaningful chemical groups and support molecule selection for research or screening.

Work Flow

1️⃣ Search: Enter SMILES, CID, name, or import a MOL/SDF file.
2️⃣ Similarity Scan: Tune the Tanimoto threshold (70–98%) and refine your result set.
3️⃣ Key Descriptors: Get a first selection with instantly view of MW, XLogP, TPSA, HBD/HBA, Rotatable Bonds, and Complexity of alternative molecule.
4️⃣ Smart Clustering: Map all selected molecules with PCA or UMAP and choose your cluster count (K).
5️⃣ Insights: Reveal the closest analogs within the final, optimized cluster.

Final Applications

ChemioInfo can be used for lead discovery, scaffold hopping, and drug repurposing, as well as for gaining insights into toxicity and ADME profiles. It also supports the analysis and optimization of chemical libraries to guide better decision-making in research and development.

Molecule

Molecule Name: It is the common or IUPAC name of the compound for identification.
SMILES: It is a text string encoding a molecular structure (atoms, bonds, rings).
CID: It is the PubChem identifier for a molecule, used to fetch structure and properties.
MOL: It is a chemical file format that stores a molecule's 2D or 3D structure used for visualization and computational analysis. Confirm loading with "ENTER" on CID box

Tanimoto Selection Protocol

The Tanimoto selection protocol compares 2D molecular fingerprints (structural patterns, not physicochemical properties) between more than 1M compounds in the PubChem DataBase. It computes a Tanimoto similarity score and selects molecules whose 2D structural features are most similar to the chosen reference.

Clustering Approach (PCA/UMAP)

The clustering uses the properties (MW, XLogP, TPSA, complexity, etc.) to describe each compound numerically. PCA & UMAP reduces the multidimensional property vectors into 2D space, allowing molecules with similar profiles to group together. Clusters reveal families based on shared physicochemical features.
PCA is a linear dimensionality-reduction method that transforms molecular property data into a smaller set of components. It preserves the largest variance in the dataset and produces results that are easy to interpret.
UMAP is a non-linear dimensionality-reduction method that builds a graph based on local relationships between molecules. It preserves local structure, meaning it groups very similar molecules tightly together.
